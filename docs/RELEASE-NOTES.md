First public release.

- **Welcome screen** on first launch: quick setup (username, Vincent multiplier, sounds, auto-accept), the warp key, and shortcuts to the HUD editor and full settings. Reopen it any time with `/trevorplus welcome` or from the settings menu.
- Diagnostic commands are no longer part of the normal command list.
- Quieter log: routine quest events are only logged in debug mode.
- Auto-hide delay is configurable (menu or `/trevorplus autohide <seconds>`), and the warp key and auto-accept also switch off while hidden.
- Every chat line Trevor+ prints has its own toggle in the menu.
- The settings menu is paged when it does not fit on screen.

Requires Fabric API. Minecraft 26.2, Java 25, client-side only.
