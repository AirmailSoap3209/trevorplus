- **Custom rarity colours**: change the colour of each rarity (Trackable to Elusive) for the mob box, its label, banners and HUD text. Settings > Colours opens a colour picker with a saturation/brightness square and hue bar (every colour), R/G/B sliders and a hex code box you can type or paste into. "Default" puts a rarity back.
